Text-to-SQL Agent — System Schematic

Runtime Architecture: Natural Language to Safe SQL Result

Row data never leaves the local database — only schema metadata and the user's question reach the LLM. Two traces run in opposite directions: the request trace builds context, the response trace validates and executes it.
